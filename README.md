Scripts and processed data for the Glacial lake Microbiome Project (GlaciallakePRJ).

## Metagenomic Analysis

`Metagenomic Analysis/` contains the metagenomic analysis workflow:

- Quality control and trimming
- Metagenomic assembly
- ORF prediction
- MAG binning, quality assessment, and dereplication
- Genome abundance calculation
- Functional annotation

## R scripts

`R_scripts/` contains scripts for:

- Linear mixed-effects model analysis
- MAG–carbon-source bipartite network analysis
